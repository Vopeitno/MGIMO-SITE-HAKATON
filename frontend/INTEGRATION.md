# Состояние интерфейса после восстановления исходной версии

18.11.2026 по запросу владельца восстановлена исходная разметка из HEAD до начала серверной разработки. Предыдущая интеграция сохраняла CSS, но заменяла содержимое большинства экранов универсальными компонентами; это оказалось лишним изменением интерфейса.

## Что работает сейчас

- Исходные студенческие страницы, карточки, сетки, мобильная навигация и кабинеты сотрудников.
- CSS обоих кабинетов побайтно совпадает с исходным. 27 функций студенческих компонентов, кроме необходимой переработки входа, совпадают с исходными.
- Настоящий вход через Go API в исходной форме. Переключатель роли подставляет только email; доступ определяется ответом сервера, а не выбором в форме.
- Восстановление сессии через HttpOnly refresh cookie, уведомление об истечении сессии и серверный выход.
- В меню показано имя вошедшего пользователя. Пароли и токены не зашиты в интерфейс.
- Сборка, проверка кода и 6 тестов API-клиента проходят. Вход всех шести аккаунтов из backend/.env, их роли и UUID подтверждены через настоящий сервер; тестовые сессии завершены.

## Следствие отката

Содержимое остальных исходных экранов снова демонстрационное. Их прежние локальные действия и сообщения не подтверждают запись в PostgreSQL или MongoDB. Серверные маршруты, миграции и проверки сохранены, но полноценная привязка данных к исходной вёрстке требует отдельной дальнейшей работы. Визуальную структуру при этой работе менять нельзя.

Предыдущие универсальные компоненты сохранены в frontend/integration/ConnectedScreens.tsx и frontend/integration/RequestDraftForm.tsx как отключённый код. Они не импортируются действующим приложением. Их можно использовать как источник логики запросов, но нельзя подменять ими исходные экраны.

API-клиент остаётся в frontend/api.ts, префикс /api/v1/MGIMO, Vite proxy localhost:8080. Перенос исходников в frontend сохранён согласно AGENTS.md.
