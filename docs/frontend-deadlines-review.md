# «Дедлайны»: серверные данные, только просмотр

20.11.2026 владелец принял «Расписание», выбрал «Дедлайны» следующим экраном и отдельно указал «Только просмотр дедлайнов». Новые таблицы, отметки выполнения и API записи не добавлялись.

## Что подключено

GET /academic/deadlines и /academic/subjects загружаются целиком с учётом пагинации. Доступ к дисциплинам и заданиям ограничивает Go API: студент видит только свои курсы через courseGroup. Профиль и уведомления обеспечивают актуальные имя, группу, инициалы и индикатор непрочитанного в оболочке. Прямая ссылка /#deadlines поддерживается после входа.

Исходные карточки, таблица, классы, CSS, шрифты и размеры сохранены. Демонстрационные массивы и localStorage done-deadlines в активном компоненте удалены. Дата, время, название курса и задания берутся из API. Все сроки отображаются в Москве, с фактическим месяцем и годом. Ближайшие задания идут первыми, без даты — в конце. Некорректная/отсутствующая дата не заменяется вымышленным сроком.

«Все» показывает весь доступный список. «Активные» — задания с уже наступившим/неуказанным началом и неистёкшим/неуказанным окончанием. Срочными считаются уже открытые задания со сроком не позднее 48 часов, включая просроченные. Будущее начало подписано отдельно, просрочка — «Срок истёк». Нет данных — пустое состояние, ошибка не маскируется демоданными.

Отметки выполнения отключены с пояснением. Фильтр «Выполнено» отключён, поскольку данных об исполнении нет. Карточки «выполнено» и «сдано вовремя» показывают прочерк вместо вымышленных нулей/процентов. Личные отметки не создаются и не трактуются как сдача преподавателю.

«В календарь» скачивает .ics для видимого списка заданий, имеющих реальный deadlineEndAt. Событие ставится точно на срок сдачи; длительность не выдумывается. В файл включены название, курс и описание из API. Значения экранируются от внедрения свойств, используются UTC и переносы UTF-8 строк до 75 байт по [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545). Без дат выводится пояснение вместо пустого скачивания. Файл нужно импортировать в выбранное приложение календаря; сообщение не утверждает автоматического добавления события.

## Проверки

23 проверки клиента/моделей/сохранения исходных тегов, классов и стилей. Сборка TypeScript/Vite и ESLint. Модель проверена на пустые ответы, просрочку, будущее начало, московскую дату на границе суток и календарный файл с длинной кириллицей/переносами/разделителями. Загрузчик проверяется для двух студентов на облачной базе, только чтение: сравнение названий, описаний, сроков, курсов и группы с реальными ответами API; временные сеансы завершаются logout.

Браузерная автоматизация ранее недоступна. Результат открывается системной командой open в Chrome по разрешению владельца. Проверка HTML не заменяет визуального отзыва. После открытия ждать отзыва; другие экраны не менять без согласования.
