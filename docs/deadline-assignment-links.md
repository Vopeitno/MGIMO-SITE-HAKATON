# Ссылки на сдачу: преподаватель → студент

20.11.2026 владелец выбрал переход на внешнюю учебную платформу. Затем уточнил: пока использовать общий Moodle, а в кабинете преподавателя дать возможность прикреплять ссылку к конкретному заданию. Не требуется ждать реальных адресов заданий для общего перехода.

## Как это работает

Без отдельной ссылки дедлайн открывает `https://ed.mgimo.ru/`. Этот адрес Moodle указан в [учебной документации МГИМО](https://mgimo.ru/upload/iblock/dba/5tisjnca48te1hmtsdrxkbz7zqxiblu4/otvetstvennost-za-prestupleniya-v-sfere-vysokikh-tekhnologij-i-informaczionnoj-bezopasnosti.pdf). Общий адрес задаётся серверной `MOODLE_URL`, уже заполненной в локальном .env. Доступность внешнего сайта и авторизация в нём не контролируются нашим приложением.

Преподаватель открывает свой раздел «Дедлайны», видит задания только своих дисциплин, вставляет HTTPS-ссылку и нажимает «Сохранить ссылку». Студент при нажатии на название дедлайна или иконку книги открывает эту ссылку. «Вернуть общий Moodle» удаляет отдельную ссылку. Студентам не выдаются права изменения. Загрузка работы, проверка и оценивание остаются на внешней платформе.

Настройка JSON по идентификаторам заданий через .env удалена: прежняя DEADLINE_SUBMISSION_URLS больше не используется. Преподаватель сохраняет ссылки через интерфейс, общий Moodle настраивается один раз.

## Хранение и доступ

Миграция `002_deadline_links.sql` добавляет отдельную таблицу, не меняя прежние сущности:

- deadlineID — PK/FK на deadlines, ON UPDATE/DELETE CASCADE.
- submissionURL — HTTPS-ссылка до 2048 символов.
- updatedByTeacherID — автор изменения, FK на teachers, ON UPDATE CASCADE/DELETE SET NULL.
- updatedAt — серверное время изменения.

Удаление задания удаляет ссылку; удаление преподавателя сохраняет ссылку и обнуляет автора. RLS включена, права PUBLIC/anon/authenticated отозваны. Изменение проходит только через Go API. Преподаватель должен быть назначен дисциплине через courseTeacher. На время записи блокируются задание, дисциплина и назначение преподавателя, чтобы параллельное снятие назначения не обходило проверку доступа. Отсутствующее и чужое задание одинаково возвращают 404. Остальные роли, включая ADMIN, получают 403.

## API

`GET /api/v1/MGIMO/academic/deadlines` дополняет доступные задания:

- submissionURL — итоговый адрес: ссылка преподавателя или общий Moodle.
- customSubmissionURL — отдельная ссылка либо null при общем Moodle.

`PATCH /api/v1/MGIMO/academic/deadlines/{deadlineID}/submission-link`, только TEACHER, JSON `{ "submissionURL": "полный HTTPS-адрес" }`. Значение null возвращает общий Moodle. Отсутствующее/неизвестное поле — 400, недопустимая ссылка — 422. Разрешены только абсолютные HTTPS-адреса без логина/пароля и управляющих символов. Студент не может прислать URL через GET и изменить конфигурацию. Сервер не скачивает внешние страницы.

Обновлены оба источника OpenAPI и DBML. Сроки, описание задания, оценки и прочие сущности не изменяются. Показатели фактической сдачи не выдумываются: интеграции получения результатов из Moodle нет.

## Интерфейс и проверка

Студенческий переход сохранён в принятом виде. В кабинете преподавателя добавлены пункт «Дедлайны» и форма в существующих role-card/role-row/role-primary; исходный CSS не менялся. Общие демонстрационные показатели других разделов не перенесены в новый раздел ссылок. Прямая ссылка `/#teacher-deadlines` открывается после входа преподавателя; аутентификация остаётся обязательной.

Проверены сохранение/чтение/сброс, отказ другому преподавателю и остальным ролям, валидация ссылок, каскады удаления на изолированной локальной схеме. На облачном сервере преподаватель временно сохранил настоящий общий адрес Moodle, оба студента прочитали его, остальные роли получили 403; исходная настройка восстановлена. Уроки, оценки и прочие учебные данные не менялись. Миграция применена локально и в Supabase.

27 проверок клиента/моделей/форм/сохранения оформления, облачный загрузчик студентов и преподавателя, Go tests/vet, TypeScript/Vite, ESLint и согласованность контрактов проходят. Браузерная автоматизация ранее недоступна; для показа используется разрешённая системная команда open. Проверки HTML и API не подменяют визуального отзыва.
