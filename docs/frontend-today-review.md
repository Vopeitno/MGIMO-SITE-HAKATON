## Подключённые данные

| Элемент исходного экрана | Источник |
| --- | --- |
| Приветствие, инициалы | Пользователь из серверной авторизации; дата отображается по Москве |
| Группа в боковой панели | `/profile/me`, связанная группа студента |
| Индикатор новых уведомлений | `/notifications`, отметки прочтения из базы |
| Следующая пара | `/dashboard`, неотменённые будущие занятия |
| Расписание на сегодня | `/schedule?date=…`, московская календарная дата |
| Последние заявки | `/dashboard`, собственные обращения; при нажатии читается карточка через `/requests/{id}`, краткий результат показывается существующим уведомлением |
| Средний балл, закрытые дисциплины и прогресс | Полные страницы `/academic/subjects` и `/academic/grades`; отсутствие оценки не приравнивается к нулю |
| Ближайшие дедлайны | `/dashboard`, названия дисциплин из `/academic/subjects` |

Короткий номер заявки — первые восемь символов серверного UUID; полный идентификатор сохраняется для запросов. Загрузка, ошибка и отсутствие записей показываются в существующих текстовых местах карточек. Демонстрационных подстановок при ошибке API нет. Форма новой заявки на этом этапе не подключена: соответствующая кнопка сообщает о недоступности вместо ложного создания.

Сами данные первоначального заполнения БД вымышленные, как требует техническая документация. Они хранятся в PostgreSQL и выдаются сервером; это не встроенные в интерфейс массивы.
