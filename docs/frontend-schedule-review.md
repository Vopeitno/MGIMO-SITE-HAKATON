# Подключение «Расписания» — 19.11.2026

Владелец отдельно выбрал «Расписание» после принятия PDF-выписки. Исходный компонент сохранён; заменены источники данных и обработчики. CSS не менялся. Теги, классы и размеры при одинаковом числе занятий совпадают с исходными — проверено сравнением отрисованного HTML.

## Поведение

- По умолчанию текущая дата в Москве. «День»: GET /schedule?date=…; «Неделя»: GET /schedule/period?from=…&to=…. Неделя с понедельника по воскресенье, переходы между месяцами и годами без зависимости от часового пояса устройства.
- Пять исходных колонок будних дней сохранены. Суббота/воскресенье добавляются тем же компонентом только при наличии занятий, чтобы не скрывать их.
- Фильтры «Все занятия», «Очно», «Онлайн» применяются к полученным данным. Сортировка по startAt, затем lessonID. Название, преподаватель, аудитория и формат берутся из API.
- Активные/отменённые/перенесённые занятия отмечаются по серверным статусам. Онлайн-вход допускает только HTTP/HTTPS, открывается без доступа к исходному окну. Отменённое занятие не открывает ссылку.
- Пустой будущий/прошлый период не подменяется демонстрационными парами. Во время загрузки/ошибки данные предыдущего периода скрыты; запоздалый ответ при быстром переключении не заменяет актуальный.
- История GET /schedule/changes загружается полностью через пагинацию. Показываются изменения занятий выбранного периода, а также переносы из/в этот период по oldStartAt/newStartAt. Причина и время — из API; пометка «Прочитано» не имитируется, поскольку такой отметки в модели истории нет.
- Имя, группа, инициалы и индикатор уведомлений используют профиль текущего аккаунта. Статичный демонстрационный заголовок с ноябрьскими датами заменён описанием «Занятия вашей группы»; выбранный период указан в существующей карточке.
- Доступ сервера по прежнему контракту: студент видит только свою группу. Новых таблиц и атрибутов нет. Прямая ссылка /#schedule восстанавливается после входа.

## Проверки и ограничения

20 проверок клиента/моделей/сохранения оформления, сборка TypeScript/Vite и ESLint проходят. Все Go-тесты и go vet проходят. Три загрузчика Today/Grades/Schedule проверены с двумя студентами на облачной PostgreSQL: сравнение с ответами API, группа, история и пустой 2099 год. Учебные данные не изменялись; временные проверочные сеансы завершены.

Автоматическая проверка браузерного изображения недоступна: ранее браузерный инструмент сообщил об отсутствии подключения. По разрешению владельца результат открывается системной командой в Chrome. HTML-проверка подтверждает структуру, но не подменяет визуальный отзыв владельца. После открытия ждать отзыва; другие экраны не подключать без выбора владельца.

Исходная БД не хранит историю принадлежности студента к группам; расписание выбирается в пределах нынешней группы согласно действующему API. Демонстрационные экраны, не выбранные владельцем, не менялись.
