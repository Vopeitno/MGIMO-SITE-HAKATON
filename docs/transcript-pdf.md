# Выписка об успеваемости в PDF

Согласовано владельцем 19.11.2026: полностью заменить табличный экспорт на PDF с аккуратным шаблоном документа. Позже по прямому запросу владельца добавлен выбор года обучения рядом с прежней кнопкой; использованы существующие классы и оформление. Остальная разметка, CSS, шрифты и размеры страницы сохранены.

## Контракт и данные

`GET /api/v1/MGIMO/academic/transcript.pdf`, только роль STUDENT. Идентификатор берётся из проверенной серверной сессии. Допустим единственный параметр `year`: номер года обучения 1–50 либо `all`. Без параметра выбирается текущий год. Неизвестные параметры, дубли, нулевые/отрицательные/некорректные значения отклоняются с 400. Остальные роли получают 403, запрос без авторизации — 401. Ответ: `application/pdf`, `Content-Disposition: attachment`, `Cache-Control: no-store`. Альтернативных форматов нет.

Сервер читает согласованный снимок PostgreSQL в транзакции REPEATABLE READ READ ONLY. Включены ФИО, номер студента, группа, факультет и направление; дисциплины текущей группы через courseGroup, семестр, часы, собственные courseScore.score/credit. Дубли назначений группы не дублируют дисциплины. Паспорт, пароль, контакты и чужие оценки не выбираются. Исторические группы отдельно не восстанавливаются: такой модели в текущей схеме нет.

Шкала баллов 0–100 остаётся исходной. Ноль сохраняется, отсутствие оценки обозначается прочерком. Среднее считается только по выставленным баллам; зачёты — по credit=true. Пятибалльные оценки не выдумываются. Пустой список формирует документ с пояснением.

## Годы обучения

1-й год — семестры 1–2, 2-й — 3–4 и далее: semester в существующей модели — последовательный номер семестра учебного плана. Схема БД не изменена. Текущий год определяется по году studentEnrollmentDate и началу учебного года 1 сентября по Москве; до начала первого года выбирается первый. Это вычисляемое значение, без учёта академических отпусков и переводов: их история в текущей модели отсутствует.

`GET /academic/transcript/periods` возвращает currentYear и непрерывный список years от 1 до максимума текущего года и года доступных дисциплин. Годы без назначенных дисциплин не пропускаются. С началом следующего учебного года список расширяется автоматически при следующей загрузке экрана, без обновления приложения. В выпадающем списке текущий выбран по умолчанию; также есть «Все годы». Фильтр применяется внутри серверного запроса PostgreSQL, затем вычисляются итоги. Период указан в PDF и имени скачиваемого файла. Пустой выбранный год формирует PDF с пояснением, не подставляет данные другого года. При `year=all` объединение происходит только по явному выбору.

## Шаблон

A4, тёмно-синяя шапка таблицы, спокойные серые разделители, чередующиеся строки, встроенные шрифты Go Regular/Bold с кириллицей. ФИО и названия переносятся по словам. Строки таблицы не разрываются между страницами. На следующих страницах повторяются заголовки, внизу — номера страниц. Итоги переносятся вместе с последней строкой при нехватке места. Дата формирования указана в московском времени.

Документ оформлен в деловом стиле, но содержит пометку учебного прототипа согласно требованиям проекта. Печать, подпись и регистрационный номер университета не имитируются.

Генерация — Go, библиотека gopdf, без внешних сервисов, браузерной печати или сетевой загрузки шрифтов. PDF не сохраняется на сервере. Два параллельных слота генерации, таймаут 15 секунд, максимум 2000 дисциплин; превышение не приводит к выдаче неполной выписки. Временные проверочные документы находятся вне репозитория.

## Приёмка

- Все Go-тесты проходят, включая пустую выписку, нулевой балл, отсутствие оценки, длинную кириллицу, 65 дисциплин, отмену и превышение лимита.
- 17 проверок клиента, моделей и сохранения исходных тегов/классов/стилей проходят; TypeScript и сборка Vite проходят.
- Poppler подтвердил A4, корректный текст кириллицы, наличие всех 65 дисциплин и номеров страниц. Проверено изображение одностраничной и многостраничной выписки.
- На работающем сервере проверены PDF двух разных студентов, изоляция их данных, заголовки ответа, отказ другим четырём ролям и проверка допустимых/недопустимых параметров запроса.
- PDF принят владельцем; выбор года по его просьбе не требует повторного показа. Следующим отдельно выбран экран «Расписание».
