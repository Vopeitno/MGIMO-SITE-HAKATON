# «Успеваемость» и перенос быстрых кнопок — 19.11.2026

Владелец принял экран «Сегодня», сообщил о разрыве слова «Успеваемость» и разрешил продолжить в том же формате. Следующим экраном отдельно выбрана «Успеваемость». После показа этого этапа снова требуется дождаться отзыва.

## Исправление переноса

В узких двухколоночных ячейках иконка и подпись не помещались рядом. Для `.quick-title` и `.quick-sub` убран перенос внутри слов. Карточка быстрых действий стала именованным CSS-контейнером: при ширине её содержимого не более 400px кнопки выстраиваются в одну колонку. При достаточной ширине сохраняются две колонки. Размеры шрифта, отступы внутри кнопок, иконки, цвета и скругления не менялись. Это явное согласованное исключение из прежней полной идентичности CSS.

## Данные «Успеваемости»

- Дисциплины и назначенные преподаватели: полные страницы `/academic/subjects`.
- Баллы и зачёты: полные страницы `/academic/grades`, только в рамках серверных прав.
- Курсы без оценки не исчезают; `null` отображается прочерком, нулевой балл остаётся нулём.
- Средний балл рассчитан по выставленным результатам в шкале 0–100. Фиктивная пятибалльная шкала не используется.
- Количество зачтённых дисциплин рассчитано по ответу сервера. Маркеры в существующих квадратах показывают состояние зачёта, а не выдуманные оценки 4/5.
- Показатель посещаемости в API отсутствует. Карточка сохранена, значение — прочерк, без прежних демонстрационных 86%.
- Нажатие дисциплины читает `/academic/subjects/{courseID}/results` и показывает краткий результат в существующем уведомлении.
- Кнопка выписки скачивает PDF с сервера: личные данные, дисциплины, часы, семестры, баллы, зачёты и итоги. Шаблон A4, кириллица, переносы и нумерация страниц. Подробнее — [transcript-pdf.md](transcript-pdf.md).
- Имя, инициалы, группа и индикатор уведомлений в общей оболочке этого экрана также используют серверные данные. Заголовок не содержит фиктивного семестра или курса обучения.

Для сохранения подписи преподавателя в исходной строке в ответы курса добавлено необязательное вычисляемое поле `teachers`. Оно получается через существующую `courseTeacher JOIN teachers`, содержит только `teacherID` и `teacherName`, не добавляет колонок и не меняет схему БД. Оба источника OpenAPI обновлены согласованно.
